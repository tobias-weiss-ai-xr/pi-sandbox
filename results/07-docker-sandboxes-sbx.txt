Status: NOT installed. Docker Sandboxes is a separate Docker product/CLI (`sbx`)
  that must be installed independently of Docker Desktop. Its value is a managed
  sandbox with a credential proxy that keeps the real provider key on the host and
  substitutes a placeholder inside the sandbox.

To activate: install the `sbx` CLI from Docker, then:
  sbx secret set anthropic   (for an API key)  OR
  sbx secret set-custom --host api.anthropic.com --env ANTHROPIC_OAUTH_TOKEN \
     --placeholder 'sk-ant-oat01-{rand}'   (for a Claude Pro/Max OAuth token)
  sbx run --kit "docker.io/sbx/pi-kit:latest" pi
