# results/ — index

Raw probe outputs, committed as reproducible evidence. Filenames are
`NN-<host>-<method>.txt`; the host suffix is omitted for the original
Windows run and is one of `-legion` (native Linux) or `-macos` (Colima).

Safety: every file is existence/size + env-var-**name** output only — never
secret contents. Verify the corpus with `make check` (see
`harness/check-invariants.sh`).
